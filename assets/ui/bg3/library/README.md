# BG3 Wiki Asset Library

Generated from bg3.wiki for local prototype UI references.

- `relics/`: original-size equipment icons from Rings, Amulets, Headwear, and Handwear.
- `skills/`: original-size spell, action, and illithid-power icons.
- `effects/`: original-size condition and effect icons.
- `monsters/`: original-size creature images for future encounter content.
- `monsters/creatures/{water_myrmidon,phase_spider_matriarch,raphael,ketheric_thorm}.png`: stable Stage1 boss portraits.
- `skills/actions/{hiemal_strike,venomous_bite,venom_claws,owlbear_claws,diabolic_chains,ketheric_smite}.png`: stable Stage1 boss skill icons.
- `quests/`: quest and journal imagery for future campaign content.
- `../relics/assigned/`: stable icons consumed by the current relic UI.

Source metadata is in `metadata.json`.
